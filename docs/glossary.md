# 用語集

本書の導入時点で参照しやすいよう、頻出用語を最小限に整理します。

## WSL2

Windows Subsystem for Linux 2。Windows 上で Linux カーネル互換の実行環境を提供する仕組みです。

## ディストリビューション

Linux カーネルとユーザー空間ツールを組み合わせて配布される実行環境です。本書では主に Ubuntu を前提に扱います。

## シェル

Linux でコマンドを入力して操作するためのインターフェースです。Bash は代表的なシェルの一つです。

## パッケージマネージャ

ソフトウェアの導入、更新、削除を管理する仕組みです。Ubuntu では `apt` を利用します。

## systemd

サービス起動やシステム管理を担う初期化システムです。WSL2 では設定により有効化できます。

## LAMP

Linux、Apache、MySQL、PHP の組み合わせを指す通称です。第6章の WordPress 構築で扱います。
